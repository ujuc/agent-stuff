# CLAUDE.md — skills

Skill definitions for Claude Code. Each skill is a `SKILLNAME/SKILL.md` with optional `references/` for supplementary material.

## Work Rules

- Follow the frontmatter spec at `generate-skills/references/frontmatter-spec.md` for all skill metadata
- Skill files are English by default; Korean only in user-facing trigger descriptions
- When modifying a skill, update `README.md` if the skill's purpose or model assignment changed

## Behavioral Guidelines

- `learned/` is auto-generated by external plugins — do not track, add to `.gitignore` if it persists
- Do not duplicate skill logic across skills; extract shared patterns into `references/` files
- The 5 harness skills (spec-planner → sprint-contract-negotiator → generator → qa-evaluator/frontend-design-evaluator) form a pipeline orchestrated by multi-agent-orchestrator — changes to one may affect the chain
